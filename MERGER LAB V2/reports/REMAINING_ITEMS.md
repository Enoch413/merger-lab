# 잔여 오류 및 미검증 사항

## 확인된 잔여 오류

- 없음.

## 운영 전 참고

- 다른 컴퓨터에는 Python 3, `lxml`, `Pillow` 설치가 필요하다. 이번 ZIP은 Python 런타임을 포함한 단일 EXE가 아니다.
- 실제 프린터의 종이 출력은 수행하지 않았다. 한글 2022가 생성한 PDF 인쇄 결과까지는 PASS다.
- 새 지문 번호별 범위 기능은 HWPX 내부 머리말 XML과 자동화 검사로 확인했다. 이 기능의 서로 다른 범위가 한 문서에서 전환되는 장면은 한글 2022로 다시 PDF 렌더링하지 않았다.
- 화면 캡처 자동화는 사용하지 않았다. 실제 HWPX 열기와 PDF 변환 성공, PDF 페이지 렌더 시각 검수로 대체했다.
- 기존 운영 폴더는 사용자의 미커밋 수정이 있어 그대로 보존했다. 운영 투입은 별도 V2 폴더/ZIP으로 한다.
