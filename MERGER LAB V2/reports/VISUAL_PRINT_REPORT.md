# 실제 화면·인쇄 검사 결과

## 검사 방법

대표 HWPX 5개를 한글 2022의 `HWPFrame.HwpObject`로 실제 열어 PDF로 저장했다. 생성 PDF를 Poppler로 페이지별 PNG로 렌더링한 뒤 눈으로 확인했다. XML 검사만으로 시각 PASS를 선언하지 않았다.

## 결과

| 파일 | 한글 열기·PDF 저장 | 페이지 | 시각 검사 |
|---|---:|---:|---|
| T01 전자레인지 미포함 | PASS | 4 | 04와 05가 같은 최종 페이지에 정상 배치, FLOW 선·라벨 선명 |
| T02 전자레인지 포함 | PASS | 4 | 03 영어 아래 보라색 발음, 우측 직독직해, 겹침·잘림 없음 |
| T03 애도 미포함 | PASS | 3 | BRANCH 분기·우측 우회 Edge·병합 구조 정상 |
| T04 애도 포함 | PASS | 4 | 긴 영어·발음·해석 행 높이 확장, 05 별도 최종 페이지 정상 |
| T06 다중 지문 포함 | PASS | 8 | 두 지문 순서, 각 05 도식, 서로 다른 이미지 모두 정상 |
| T13 학교·범위 포함 | PASS | 8 | `한빛고등학교` 왼쪽 위, `1학기 중간고사 1~3강` 오른쪽 위, 두 지문 적용 정상 |

검사 PDF는 `reports/*_after_template_replacement.pdf` 및 `tmp/pdfs/T13_school_range_included.pdf`, 렌더링 이미지는 `tmp/pdfs_after/`와 `tmp/pdfs/`에 있다. T01/T02의 빈 3페이지와 T04의 03 분리는 기존 템플릿의 고정 페이지 배치에서 이어진 동작이며, 05 삽입으로 새 빈 페이지가 생긴 것이 아님을 기존 운영 출력과 비교했다.

직접 모니터 화면 캡처는 사용하지 않았고, 한글 2022 엔진이 만든 실제 PDF 인쇄 결과를 시각 검수했다.
