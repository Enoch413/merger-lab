# 학교·범위 머리말 업그레이드

실행일: 2026-10-15

## 구현

- 화면에 `학교 · 왼쪽 위` 입력란과 여러 개의 `범위 · 오른쪽 위` 구간 행을 추가했다.
- 범위 행은 최종 지문 번호의 시작·끝·표시 문구를 입력하고 추가·삭제할 수 있다.
- 학교와 범위 구간은 `/api/build-bundle` 요청의 별도 표시 옵션으로 전달한다. 기존 단일 `range` 요청도 계속 지원한다.
- 서버는 문자열·줄바꿈·40자 제한뿐 아니라 양의 정수, 시작≤끝, 실제 지문 번호 범위, 겹침, 미지정 지문을 검사한다.
- 생성기는 템플릿의 기존 머리말 도형·글꼴·색상·정렬을 유지하고 텍스트만 교체한다.
- 두 값은 `MASTER_ANALYSIS_merged.json`에 추가하거나 원본 지문 데이터를 변경하지 않는다.
- 빈 입력은 템플릿의 기존 머리말을 유지한다.

## 검증

- 발음 포함, V2, 전자레인지→애도 다중 지문으로 T13을 생성했다.
- HWPX 내부 두 지문 머리말 모두 `한빛고등학교` / `1학기 중간고사 1~3강`으로 확인했다.
- 한글 2022에서 실제 열어 A4 8페이지 PDF로 저장했다.
- 첫 번째·두 번째 지문의 출력 페이지에서 왼쪽 학교, 오른쪽 범위의 위치·가독성·잘림 없음 확인: PASS.
- 통합 JSON이 입력 승인 JSON과 동일함을 확인: PASS.
- `1~10 / Q미니S 10강`, `11~20 / Q미니S 11강` 직접 매핑: PASS.
