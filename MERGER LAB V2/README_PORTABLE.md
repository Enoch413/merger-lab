# MERGER LAB V2 — 다른 Windows 컴퓨터에서 실행

1. 배포 ZIP을 압축 해제하고 폴더 구조를 그대로 유지합니다.
2. Python 3가 없다면 <https://www.python.org/downloads/>에서 설치합니다. 설치 시 Python Launcher(`py`)를 포함하세요.
3. 명령 프롬프트에서 `py -3 -m pip install lxml pillow`을 한 번 실행합니다. `py`가 없으면 `python -m pip install lxml pillow`을 실행하세요.
4. `START_MASTER_ANALYSIS_BUNDLE.bat`을 더블클릭합니다. 브라우저가 열리지 않으면 <http://127.0.0.1:8782/>에 접속하세요.
5. JSON을 업로드하고 지문 순서, 학교·범위 머리말, 발음 옵션, 교재 출력 모드를 선택한 뒤 ZIP을 다운로드합니다.

## 출력 모드

- `V2 논리 시각화 (00~05)`: 모든 지문에 유효한 `논리_시각화`가 있어야 합니다. 04 어휘표 다음에 05 도식을 실제 PNG 이미지 객체로 넣습니다.
- `기존 호환 (00~04)`: `논리_시각화`가 없는 구형 JSON도 기존 교재 형식으로 생성합니다.

V2의 `reading_order`는 화면 배치·읽기 순서이고 Edge의 `from`→`to`는 실제 논리 방향입니다. 따라서 근거가 앞의 주장을 뒷받침하는 `N3`→`N1` 같은 관계도 허용되며, 도식에서는 노드 바깥쪽 우회 화살표로 표시됩니다.

발음 포함을 선택하면 모든 문장의 `한글발음`이 비어 있지 않은 문자열이어야 합니다. 발음 옵션과 출력 모드는 HWPX 표시만 바꾸며, 다운로드 ZIP의 `MASTER_ANALYSIS_merged.json`은 지문 번호 재부여 외에 입력 데이터를 변경하지 않습니다. V2 ZIP에는 검수용 `diagrams/logic_*.png`도 들어갑니다.

학교를 입력하면 모든 페이지 머리말 왼쪽 위에 표시됩니다. 오른쪽 범위는 최종 지문 번호별 구간을 여러 개 추가할 수 있습니다. 예를 들어 `1~10 / Q미니S 10강`, `11~20 / Q미니S 11강`으로 지정하면 각 지문에 속한 범위가 자동으로 들어갑니다. 구간을 사용할 때는 모든 지문 번호를 빠짐없이 한 번씩 포함해야 하며, 겹치거나 누락된 번호는 생성 전에 안내합니다. 머리말 값은 HWPX 표시 옵션이며 통합 JSON에는 추가되지 않습니다.

기본 템플릿은 사용자가 편집한 `T01_microwave_excluded.hwpx`를 재사용 가능한 형태로 변환한 파일입니다. 발음 포함 템플릿도 이 파일을 바탕으로 만들었으며, 00·01·02·04·05는 발음 미포함 템플릿과 동일하고 03의 문장별 발음 줄과 그 전용 서식만 다릅니다.

Python·lxml·Pillow는 배포 ZIP에 포함되지 않습니다. HWPX를 열거나 편집하려면 HWPX를 지원하는 문서 프로그램이 필요합니다. V2 서버는 기존 운영본과 충돌하지 않도록 해당 컴퓨터의 `127.0.0.1:8782`에서만 실행됩니다.
