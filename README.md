# MERGER LAB

최신 기능은 **`MERGER LAB V2` 폴더**에 있습니다.
루트 폴더의 실행 파일은 이전 운영본이며 함께 보존합니다.

## 초기화 후 복원

```powershell
git clone https://github.com/Enoch413/merger-lab.git
cd "merger-lab\MERGER LAB V2"
py -3 -m pip install lxml pillow
.\START_MASTER_ANALYSIS_BUNDLE.bat
```

Python 3와 Python Launcher(`py`)가 필요합니다. 브라우저 주소는
`http://127.0.0.1:8782/`입니다.

최신 기능: 발음 포함·미포함, 사용자 수정 기반 HWPX 템플릿,
논리 시각화, 읽기 순서와 반대 방향의 의미 Edge 지원,
학교 머리말, 최종 지문 번호별 범위 머리말.

설치·실행 상세는 [V2 안내](MERGER%20LAB%20V2/README_PORTABLE.md)를 참고하세요.
템플릿 백업, 시험 출력물과 검증 보고서도 저장소에 포함합니다.
